【既存の Apps Script に追加するコード】

既に自家製剤加算などのクイズで使用している Apps Script を開いてください。
「function doPost(e) {」の直後（最初の行）に、次のコードをそのまま貼り付けます。
既存の doPost を削除・上書きしないでください。既存のタブへの振り分けはそのまま残せます。

【保存後に必要な操作】
1. Apps Script画面右上の「デプロイ」→「デプロイを管理」。
2. 現在利用しているウェブアプリの右上の編集（鉛筆）を押す。
3. 「バージョン」で「新しいバージョン」を選んでデプロイ。
4. 既存URLが変わっていないことを確認する。
5. GitHub Pages上のクイズを最後まで解き、テスト送信。
6. スプレッドシートの「調剤時残薬」タブに1行増えたか確認する。

【注意】
- この追記だけではサイト公開はされません。index.html/style.css/script.js の3ファイルを GitHub に配置してください。
- 同じApps Scriptが既存のクイズも受信している場合、doPost 関数を2つ作らないでください。
- Webアプリのアクセス権限は従来の動作していた設定を引き継いでください。
- もし既存のタブに独自の列見出しがある場合は、上の列構成と合わせてください。
