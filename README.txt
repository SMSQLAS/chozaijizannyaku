調剤時残薬調整加算クイズ（全15問）
Repository: chozaijizannyaku

1. GitHubにアップロードするファイル（3つだけ）
   - index.html  ... クイズ画面
   - style.css   ... デザイン（紫系）
   - script.js   ... 15問・正誤判定・送信処理

2. スプレッドシートに結果を保存するための追加設定
   - GAS_PATCH.txt を開きます。
   - 既存スプレッドシートの「拡張機能」→「Apps Script」を開きます。
   - 既存の function doPost(e) { の直後に、GAS_PATCH.txt のコードを追加します。
     （これまでのクイズを動かす既存のコードは削除しない）
   - 保存し、デプロイを管理→編集→「新しいバージョン」で再デプロイします。
   - 保存先はスプレッドシートの「調剤時残薬」タブです。

3. GitHub Pagesの公開
   - chozaijizannyaku リポジトリを開く
   - Add file → Upload files で3つのファイルをリポジトリ直下に配置
   - Commit changes
   - Settings → Pages → Build and deployment
   - Source: Deploy from a branch / Branch: main / Folder: /(root) / Save
   - Pagesに表示される公開URLでテスト

4. 送信先について
   script.js 3行目付近のWEB_APP_URLには、以前の自家製剤加算クイズで使っていた
   Google Apps ScriptのウェブアプリURLを初期設定しています。
   これが現在のURLと違う場合は、WEB_APP_URLだけ現在のURLへ変更してください。
   フロント側ではブラウザの制限上、GAS側への書込み完了を直接確かめられません。
   必ず初回にテスト回答を送り、「調剤時残薬」タブに記録されることを確認してください。

5. クイズ仕様
   - 全15問（添付のWordの12問＋3問）
   - 問1～9：算定可否の2択
   - 問10～12：4択
   - 問13：3択
   - 問14：2択
   - 問15：4択
   - 1問ずつ回答 → 正解/不正解・正しい選択肢・解説 → 次の問題
   - 終了後に得点と誤答番号表示
   - 店舗名、名前、難易度（簡単／ちょうどいい／難しい）
   - 結果を送信した後だけ「もう一度する」が有効
   - 保存列：送信日時、クイズ名、店舗名、名前、難易度、得点、満点、正答率、誤答番号、回答詳細、回答時間(秒)

6. 問題文について
   問題・正解・解説は提供された「クイズ【調剤時残薬調整加算】.docx」を基に作成しています。
   表記の体裁調整以外の制度面の独自校訂は行っていません。公開前に担当者が
   内容と適用時点の調剤報酬通知・疑義解釈を確認してください。

個人情報保護：サイトとApps Scriptを公開して利用するため、保存先スプレッドシートの
共有権限や回答者の氏名の取扱いに注意してください。
